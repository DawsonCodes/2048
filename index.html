How to play

Slide all the tiles in one direction. Two matching tiles become one, and the new value goes toward your score. Each tile merges once per move.

Move← ↑ ↓ → or WASD / swipeUndoU 3 undos per runA little nudgeH 3 hints per runStart overR we’ll ask first

Classic is the familiar 4×4. Daily gives everyone the same starting board and random sequence for a UTC date; restarting replays that seed. Zen opens up a 5×5 board. Tiny is 3×3 with a 512 target. Sprint gives you 50 valid moves to score as much as you can. In Player vs CPU, each valid player move gives the CPU one turn. A blocked board stops; the other keeps going. In CPU vs CPU, watch both play. Both modes continue beyond 2048; the highest score wins when both boards are blocked (top tile breaks ties).

Your boards, undo history, and best scores save in this browser when storage is available. Each mode keeps its own run. Each new run starts with 3 undos and 3 hints. Using undo does not refund either allowance. Counts survive reloads and mode switches. CPU boards use the same starting seed and tile rules. Easy, Normal, Hard, and Insane change how the CPU chooses moves. Hidden tabs pause CPU matches. There’s no ranked leaderboard.
